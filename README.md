# Método de Newton-Raphson

Proyecto de Métodos Numéricos para resolver la ecuación x = e^(-x) utilizando Python.

## Función
f(x) = x - e^(-x)

## Derivada
f'(x) = 1 + e^(-x)

## Parámetros
- Valor inicial: 0.5
- Tolerancia: 0.001
- Iteraciones: 2

## Resultado
Raíz aproximada: 0.567143165

## Conclusión
El método de Newton-Raphson permitió aproximar la raíz de la ecuación en dos iteraciones, cumpliendo con la tolerancia establecida. La implementación en Python automatizó el procedimiento y permitió verificar la convergencia.
